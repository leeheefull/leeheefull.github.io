# Portfolio

개발자 이희찬 포트폴리오 — https://leeheefull.github.io/portfolio

## Stack

- [Astro](https://astro.build) 정적 사이트
- GitHub Pages + GitHub Actions 자동 배포

## 콘텐츠 수정

- 프로젝트 추가/수정: `src/content/projects/*.md`
- 경력·기술 스택·자격증: `src/pages/index.astro`
- `main` 브랜치에 push하면 자동으로 배포됩니다.

## 로컬 실행

```bash
npm install
npm run dev
```
