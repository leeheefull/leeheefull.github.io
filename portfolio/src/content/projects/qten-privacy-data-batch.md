- 투어 서비스에서 보유기간이 지난 개인정보와 로그 데이터를 수정 및 삭제하는 배치 프로세스 개발
- 7개의 데이터베이스와 35개 테이블에 접근하여 데이터를 안정적으로 처리하고, 시스템 이상 없이 운영
- 과거 데이터를 처리하기 위한 배치 작업에서 7,400만 건의 데이터를 문제없이 처리하여 시스템 성능에 영향을 주지 않음
- 일일 약 10만 건의 데이터를 자동으로 처리할 수 있도록 배치 작업을 활성화하고 최적화
- 레플리케이션 딜레이를 고려한 데이터 처리 로직 설계를 통해 데이터 일관성 유지
- 작업에 대한 상세 로그를 남기고, 성공 및 실패 여부를 관리자에게 실시간으로 알림 발송하여 대응이 가능하도록 함
