## 배경

- 모바일 앱 혜택 페이지의 배너가 하드코딩되어 있어, 배너 하나 바꾸는 데도 개발·배포가 필요했고 마케팅 일정에 개발이 병목이 됨
- 운영자가 직접 등록·관리할 수 있는 배너 시스템을 신규 구축

## 주요 작업

- **여행자 API**: 배너 타입별 활성 배너 조회 API (노출 기간·강도 정책 반영)
- **관리 API**: 배너 CRUD, S3 이미지 업로드, soft delete
- **매니저 어드민 UI**: 배너 등록·수정·미리보기 화면 (React)
- 특정 페이지 전용이 아닌 범용 배너 도메인으로 테이블·API를 설계해 확장 여지 확보
- 배포 후 실제 프로모션(해외 숙소 버튼형 배너 일괄 노출 등)에 적용, 노출 대상 확장(item_id) 추가 개발

## 성과

- 배너 교체가 **개발 배포 없이 운영자 셀프서비스**로 전환되어 마케팅 리드타임 단축
- 범용 설계 덕분에 후속 요구(새 페이지·새 타입)를 코드 변경 없이 수용
