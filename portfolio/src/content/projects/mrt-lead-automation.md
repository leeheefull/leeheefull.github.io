## 배경

- CMS 연동 자동화로 기술적 연동 속도는 빨라졌지만, 그 앞단인 **"어느 호텔과 계약할지 찾고 컨택하는" 영업 프로세스가 수작업**이라 직계약 확대의 새로운 병목이 됨
- 사업부 요구를 개발로 풀어내는 에픽을 리드하며, 리드 발굴 → 1차 컨택 → 후속 컨택 흐름을 자동화

## 주요 작업

- 직계약 후보 호텔 리스트에서 **컨택 포인트(담당자·이메일)를 AI로 일괄 추출**하는 파이프라인 구축 — 실제 확인된 주소(확인됨)와 이름 기반 추측 주소(예측)를 구분해 발송 안전성 확보, 수동 확인 결과를 프롬프트에 반영하며 정확도 반복 개선
- 비개발 직군도 쓸 수 있도록 **엑셀 스크립트와 Claude Code 플러그인 두 가지 형태**로 제공
- 구글시트 기반 **1차 제안 메일 일괄 전송 기능** 개발 — 필터 기반 발송, 특정 행 발송, 담당자 CC, 반송 대응, 스팸 회피 등 사업부 피드백 즉시 반영
- 2차 팔로업 메일 자동화 검토·설계, 발송 이력·응답 상태 추적 데이터 구조화

## 성과

- AI 추출로 **컨택 포인트 후보 약 7,000건**을 확보하고, 검증을 거쳐 **실제 키맨(계약 담당자) 컨택 약 1,000건**을 발굴 — 수작업으로는 도달할 수 없던 규모의 영업 파이프라인 구축
- 푸꾸옥 테스트를 시작으로 상하이·중국 도시들, 미주/유럽팀, APAC팀까지 **여러 지역 팀이 직접 요청하는 표준 프로세스로 확산** — 사업부는 회신 대응과 계약 협상에만 집중
- 직계약 확대의 병목을 기술 연동(공급) → 영업(수요)까지 **엔드투엔드로 해소** — 개발자가 직군 경계를 넘어 세일즈 오퍼레이션 문제를 직접 해결한 사례
