## 배경

- 야놀자 연동이 별도 레거시 서버에서 운영되고 있어 유지보수 비용이 크고, 다른 OTA 연동(호텔베즈, 아고다 등)과 코드·인프라가 이원화되어 있었음
- 입사 직후 첫 과제로, 서비스 중단 없이 통합 OTA 시스템(hotel-ota)으로 이관하는 작업을 담당

## 주요 작업

- **배치 모듈 이관** + 전체 숙소 동기화 배치 신규 개발 → **컨슈머 모듈 이관** (Kafka 브로커 이관 포함) → **실시간 API 모듈 이관** 순으로 단계별 진행
- 이관과 함께 배치 reader 로직 개선, DB 커넥션 수 최적화 등 성능 개선 병행
- 예약 토큰 불일치(가격 변동) 시 예약 실패 처리, 예약 생성 타임아웃 재시도 시 중복 요청 방지 등 예약 안정성 개선
- 이관 완료 후 기존 컨슈머 종료 처리 및 **레거시 서버 셧다운**으로 마무리
- 이후 객실 이미지 동기화, 재고 동기화 이슈 등 야놀자 연동 운영 전담

## 성과

- 무중단으로 이관을 완수하고 레거시 서버를 제거해 **운영 포인트와 인프라 비용 절감**
- 야놀자 연동이 통합 OTA 시스템의 표준 구조로 편입되어 다른 연동사와 동일한 방식으로 유지보수 가능해짐
- 입사 1개월 차에 시작한 과제를 통해 숙박 도메인 전반(재고·요금·예약 동기화 구조)을 빠르게 장악
