## 배경

- 한인민박이 별도 시스템(BNB)으로 운영되어 숙박 도메인에 유사 기능이 중복 개발되고 있었고, 파트너 경험도 이원화되어 있었음
- 민박 상품·예약·후기 데이터를 직계약 숙소 플랫폼(스테이넷)으로 통합해 하나의 시스템으로 수렴시키는 프로젝트

## 주요 작업

- 파트너 **예약 캘린더** 통합 — 이관 전/후 숙소가 섞인 상태에서도 동작하도록 구현
- **가격 캘린더** 통합 — 등록/사용/선점유/잔여 재고 노출 로직 재정리
- **후기 이관** — 투숙 완료된 기존(BNB) 후기를 새 체계(ACM)로 전환하는 배치 개발
- **상품 피드(네이버 EP) 마이그레이션** — 이관 시점에 피드 데이터가 끊기지 않도록 테이블 반영 및 이관 로직 처리
- 구 서비스 URL 접근을 위한 **리다이렉트 API**와 구/신 숙소 매핑 API 개발
- 통합 후 고도화 — 민박 예약 차단/복구 기능, 재고 오기입·상품 블락 로직 등 운영 이슈 대응

## 성과

- 별도 서비스 하나를 플랫폼으로 **완전 흡수 통합**해 중복 개발 제거, 민박 파트너도 직계약 숙소와 동일한 관리 도구 사용
- 예약·가격·후기·피드 데이터를 유실 없이 이관하며 서비스 연속성 유지
- 통합 이후 민박 특화 요구(TR 인상 대응, 파트너 페이지 개선)를 플랫폼 위에서 확장하는 기반 마련
