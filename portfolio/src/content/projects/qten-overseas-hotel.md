- 해외 호텔 상품 판매를 위한 시스템 개발
- 호텔 전시, 호텔 목록 조회, 호텔 상세 조회 및 관련 쿠폰, 어드민, 파트너 API 개발 담당
- 캐시 로직 적용으로 호텔 목록 조회 시 latency 약 4s에서 25ms로 개선
- 글로벌 캐시와 로컬 캐시를 구분하여 캐시 데이터를 효율적으로 관리
- 코루틴 비동기 호출 로직 도입으로 연동사 실시간 API 호출 시 latency 약 6s에서 3s로 단축
- 새로운 연동사 추가 대비를 위한 추상화 작업 및 확장성 고려한 설계
- 에러를 중요도에 따라 분류하고, 즉각 대응이 필요한 에러에 대한 알림 시스템 구축
- 로그 분산 추적 라이브러리를 활용한 MSA 구조에서의 로그 추적 용이성 확보
