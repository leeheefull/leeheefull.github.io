## 배경

- 해외 직계약 숙소는 계좌 정산이 어려운 경우가 많아, 예약별로 발급되는 **가상카드(VCC)** 로 파트너가 직접 결제 대금을 수취하는 방식이 필요했음
- 예약 확정 시 VCC 발급부터 부킹 메일까지 운영팀이 **예약 1건당 약 30분씩 수기로 처리**하고 있어, 프로모션 확대 시 운영 병목이 예상되는 상황이었음

## 주요 작업

- VCC 예약/환불 연동 — 예약 생성 시 카드 발급 정보 연계, 활성화 일자 관리, 환불 시 처리 흐름 구현
- 파트너 **바우처 메일 자동 발송** 기능 개발 — 예약 정보·VCC 결제 정보를 포함한 템플릿 구성
- 국내/해외 숙소 **템플릿 분리**, 발신자 관리, 숙소별 영문 메일 발송 여부 어드민 관리 기능
- 예약 시 추가 인원 정보 저장, 외화 스냅샷 기준 금액 표기 등 정확성 개선
- 이후 IDR 등 **신규 통화 추가**와 VCC 정산 연동 확장 대응

## 성과

- **예약 1건당 약 30분 걸리던 수기 메일링 리소스를 제거**해 프로모션 확대에 대비한 운영 병목 해소
- 예약 취소 시에도 필요한 정보가 자동 포함되어 발송되도록 확장, 파트너 커뮤니케이션의 정확도와 속도 개선
- 국내 숙소까지 발송 체계를 확장해 파트너 채널 전반의 표준 프로세스로 정착
