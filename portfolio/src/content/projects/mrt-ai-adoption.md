## 배경

- AI 도구를 개인 생산성 수준을 넘어 **팀의 업무 프로세스 자체를 바꾸는 수준**으로 활용하는 것을 목표로, 실무 적용 사례를 만들고 확산하는 역할을 수행

## 주요 작업

- **CMS 연동 자동화 Skill**: 공급사 연동 문서 크롤링 → Markdown 변환 → 데이터 매핑 → 코드 생성으로 이어지는 Claude Code Skill 제작·시연 (DerbySoft 연동에서 실전 검증, 후속 공급사에 재사용)
- **세일즈 리드 자동화**: 직계약 후보 호텔의 컨택 포인트 AI 추출 파이프라인 (누적 수천 건 처리)
- **AI 인프라 의사결정 지원**: 에이전트 인프라 증설 요청을 전수 실측·감사해 증설 보류 결정을 이끔
- **확산 활동**: Windows/WSL 설치 가이드, 업무 자동화 활용 가이드 작성으로 비개발 직군 온보딩 지원, 팀 내 활용 사례 공유 미팅 주도
- **데이터 기반 프로세스 개선**: 운영지원(SUS) 요청 136건을 전수 분석해 "운영 요청 vs 프로젝트" 판별 기준을 정립, 사업 조직의 업무 분류 체계 개선

## 성과

- AI 활용이 개인 도구를 넘어 **연동 개발·영업·운영 프로세스에 내재화**된 팀 워크플로로 정착
- 반복 업무(연동 보일러플레이트, 리드 발굴, 데이터 분류)의 상당 부분을 자동화해 팀이 설계·검증에 집중할 수 있는 구조 확보
