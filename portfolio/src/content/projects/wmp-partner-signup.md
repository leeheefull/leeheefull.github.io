## 배경

- 파트너 회원가입에 악성 등록 시도가 발생하고 있었지만, 가입 시점의 검증 장치가 부족해 비정상 파트너가 시스템에 들어올 수 있는 상태였음

## 주요 작업

- 악성 등록 시도를 차단하기 위한 회원가입 비즈니스 로직 고도화
- **공공 Open API 기반 사업자등록번호 검증**을 도입해 비정상 파트너 등록 차단
- 검증에 필요한 데이터 필드를 추가해 검증 정확도 향상
- 본인 인증 완료 파트너에게 **일정 시간 유효한 Redis 키를 발급**하는 방식으로 인증 절차 강화

## 성과

- 가입 단계에서 비정상 파트너가 걸러지는 구조를 만들어 시스템 안정성 확보
- 인증 상태를 키 기반으로 관리해 인증 우회 여지를 차단
